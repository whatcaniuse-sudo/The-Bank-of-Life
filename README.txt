BANK OF LIFE - offline phone app

1. Put these files online once (free):
   GitHub Pages: create a new repository, upload everything in this folder
   (index.html, sw.js, manifest.webmanifest, fonts/, icons/) to the main branch,
   then Settings > Pages > Source: "Deploy from a branch", branch main, folder / (root).
   GitHub gives you a link like https://YOURNAME.github.io/REPO/

2. Open that link on your phone while you have internet.
   iPhone: Safari > Share > Add to Home Screen.
   Android: Chrome > menu (three dots) > Install app (or Add to Home screen).

3. Open it once from the home screen. After that it works with no Wi-Fi or data.
   Your progress is saved on the phone.

Moving progress: in the Claude version, Money > Backup & restore > Copy backup code.
In the phone app, Money > Backup & restore > paste > Restore (tap twice).
